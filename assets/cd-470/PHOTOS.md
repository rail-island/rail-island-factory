# CD 470 - reference photos

One parametric model, `veh-cd-470`: `unit` motorCar (vlakosimdb cd 470/cd_470, the default) or trailer (cd 470/cd_070).

Prototype: Moravskoslezska vagonka Studenka, CD class 470 + 070, two prototype five-car sets built 1991 for 3 kV DC suburban service around Prague (Praha - Kolin - Pardubice, later Praha - Beroun), withdrawn 2009 and scrapped 2015; two single-deck, partly low-floor motor cars and three double-deck trailers, 132 m over the buffers, Bo'Bo' + 3 x 2'2' + Bo'Bo'. The first set 470 001/002 was dark green with a yellow band, the second 470 003/004 grey and blue (cs.wikipedia "Elektricka jednotka 470").

All files were downloaded from Wikimedia Commons (rendered by `w/thumb.php`), downscaled to at most 1600 px on the long side and saved as JPEG (quality 85). Titles are given in ASCII transliteration; the page URL is the exact percent-encoded title.
