# DB 628 - reference photos

One parametric model, `veh-db-628`: `livery` mint (vlakosimdb db_628, the default) and red (db_628vr).

Prototype: Duewag / Waggon Union / LHB two-car diesel railcar DB class 628.2 / 928.2 (1986-1989), 45.40 m over buffers (de.wikipedia "DB-Baureihe 628", en.wikipedia "DB Class 628").

All files were downloaded from Wikimedia Commons (rendered by `w/thumb.php`), downscaled to at most 1600 px on the long side and saved as JPEG (quality 85). Titles are given in ASCII transliteration; the page URL is the exact percent-encoded title.
