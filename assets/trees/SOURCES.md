# Tree references

The tree shapes were first authored procedurally in the game (`rail-island-webapp`,
`src/render/TreeGeometry.ts`) and moved here, and the stylised rework follows the same
written descriptions; the conifers' layered plates follow a user-supplied image. The
table lists what the shapes draw on.

| file | origin | author | licence | use |
|---|---|---|---|---|
| `spruce-reference.png` | User attachment in chat, 2026-10-20 | Not stated (appears to be a generated illustration) | Provided as visual reference; no redistribution licence stated | `proc-tree-spruce` (and the pine and larch Max detail): layered tiers of broad drooping faceted foliage plates on visible branches, light tops, dark undersides, trunk visible between tiers |
| (none) | https://www.rhs.org.uk/plants/13141/pinus-sylvestris/details | Royal Horticultural Society | web page, cited only | `proc-tree-scotspine`: long exposed trunk, crooked leader, broad flattened crown clusters |

| (none) | OpenTTD's temperate and sub-tropical tree sprites (https://www.openttd.org) | OpenTTD contributors | GPL-2.0, looked at only | the stylised look: per-clump light and shade, colour variation between trees, overlapping canopies |
