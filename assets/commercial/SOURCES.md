# Commercial references

**Covers** - source thumbnails and measured legacy inventory.
**Code** - generator/commercialStreets.ts
**See also** - ../../docs/models/commercial-streets.md

The thumbnails are copied from rail-island-webapp/db/buildings/thumbs.
The per-object author, source URL, license and GLB SHA-256 are recorded in inventory.json.
These are visual references; the new geometry is constructed from code.
No legacy GLB is embedded in the generator. Each family folder is exposed in the factory reference viewer.
