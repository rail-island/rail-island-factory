with any model.

## Dimensions

| Item | Value |
|---|---|
| Length | 17 940 mm |
| Width | 2 500 mm (de.wikipedia gives 2 550 mm for the family) |
| Height | 2 994 mm |
| Wheelbase | 5 725 mm (only one value given; the second wheelbase and the overhangs are not given) |
| Doors | 4 on the right side, 2-2-2-2; door width 1 250 mm |
| Floor | mid / high floor (step entrance): 540 mm at doors 1-4 |
| Engine | Mercedes OM 457 hLA, 6-cylinder diesel, at the rear; the Wikipedia pages do not state the position or the driven axle |
| Built | 1996-2007 (de.wikipedia); as Conecto G from 2002; built by Mercedes-Benz Turk at Hosdere, Turkey |
| Notes | 52 seats / 166 total; solo O 345 (Conecto C): 11 825 mm, wheelbase 5 875 mm, height 2 865 mm, doors 2-2-2; tyre size not given |

## Native vlakosimdb files

`native/bus_mb_o345/` - vlakosimdb `db/motocar` at commit `b170acf` (`#` in a folder name becomes `_`):
`index.xml`, the model XML as `model.xml` and the original BMPs (10 pixels a metre;
`x_inc` the front, `x_dec` the rear, `z_inc` / `z_dec` the right and left sides,
`y_dec` the underside). The XML gives the shell's outlines; the BMPs the doors,
windows and paint; the photographs and dimensions above everything the textures
cannot resolve (docs/models/buses.md).
