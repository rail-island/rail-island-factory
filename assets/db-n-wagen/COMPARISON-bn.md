# DB Bn vr native reference comparison

**Covers** - native pixel annotations, baseline and final orthographic errors.
**Code** - `generator/germanCoaches.ts`, `generator/dbNWagen.ts`, `generator/dbDoubleDeck.ts`, `generator/drDoubleDeck.ts`, `generator/germanCoachParts.ts`, `generator/csdCoachComparison.ts`, `generator/csdCoachReport.ts`.
**See also** - [source notes](SOURCES.md), [German coaches (n-Wagen, DB Regio and DR double-deck coaches)](../../docs/models/german-coaches.md).

Model geometry revision (SHA-256 of comparison GLB): `3a1e84bed56d40bd10cb322fa0eb02981e59ed2298fcd6b1457ae3bc20bde9d5`.

Regenerate with `pnpm exec tsx generator/csdCoachReport.ts db_bnvr`. The baseline is the first authored geometry (`native/db_bnvr/baseline.json`); baseline and final use the same annotations. Built with `variant=bn`, `livery=vr` of `veh-db-n-wagen`.

Canvases: sides 27 x 5 m (270 x 50 px), ends 3 x 5 m (30 x 50 px), including empty space, 0.1 m a pixel. Origin top left; x right, y down. Side u = 10 * source x = 10 * (Factory X + 13.2); both sides keep increasing source x, so the left (-Z) elevation is mirrored relative to an outside observer, as its BMP is. Ends are seen from outside: rear u = 10 * (z + 1.5), front u = 10 * (1.5 - z). v = 10 * (5 - y).

Each vector is (left, top, width, height). Percentages are 100*x/W, 100*y/H, 100*w/W, 100*h/H of the native canvas. Signed delta = model minus source in percentage points. MAE = sum(abs(delta)) / (4 * number of boxes). Model boxes are the bounds of actual GLB vertices of the named scopes, occluded vertices included. Only the original BMPs define the measurements, never the 4x textures.

One pixel is 0.370 pp horizontally on the sides, 3.333 pp horizontally on the ends and 2.000 pp vertically. The model was authored from these same measured boxes, so the residuals measure the transfer onto the XML bodies and the deliberate mechanical choices (1.75 m buffer spacing, round lamps, the measured door and window boxes kept to whole pixels), not photographic accuracy.
