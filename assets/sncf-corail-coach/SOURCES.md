## Figures

- Length over buffers 26.40 m, width 2.825 m, height 4.050 m, Vtu bogie centres 18.306 m, Y 32 A bogies, 42 t,
  200 km/h; A10tu 58 seats, B11tu 88 seats (fr.wikipedia "Voiture Corail", infobox).
- Liveries: 1975 light grey with the anthracite window band, orange doors and a class line under the roof
  (yellow first, green second); Teoz 2003 yellow for first class, blue for second (the same article).
- Running numbers of photographed units: A10tu 50 87 10-97 512-1, B11tu 50 87 21-97 195-2 (Commons file
  titles; UIC check digits verified).
